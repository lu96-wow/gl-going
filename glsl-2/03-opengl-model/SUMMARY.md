# 03-opengl-model 小结

做了什么: 纯讲解, 把已用 API 背后的原理串成全景.

概念:
- 异步: gl-* 只提交请求就返回, 不保证已做完 -> 编译/链接要查状态, 上传放初始化
- 7 段管线: 1输入装配(固) 2顶点着色器(可,必须) 3细分 4几何 5光栅化(固) 6片元着色器(可,画屏必须) 7逐采样(固)
- 分工: CPU造数据 -> 建GPU对象 -> 传数据(PCIe) -> 设状态 -> 执行+显示

API 回顾(为什么):
- with-gl-context                  命令发给某个上下文, 发出前先进入
- build-program 查状态             编译/链接是异步的, 返回 != 成功
- gl-buffer-data                   过慢通道一次批量上传, 放初始化
- gl-draw-arrays                   触发整条管线, GPU 并行跑着色器
- gl-viewport/gl-clear/swap-gl-buffers 光栅化与显示阶段的固定段

结论: 画屏必须顶点+片元两段(上色是片元唯一职责); 上传放初始化, 每帧只改状态+draw.
