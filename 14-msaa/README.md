# 14 MSAA —— 多重采样抗锯齿

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

物体斜边在屏幕上出现"狗牙"（锯齿）。本课搞懂锯齿的成因，并用 **MSAA
（多重采样）**消除它。MSAA 正好建在上一课 FBO 之上：多重采样渲染缓冲 +
blit 解析。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 13 复制（本课未改动）
- `lib.rkt` —— 从 13 原样复制（MSAA 是标准 gl* 调用，内联在步骤里）

1. `01-msaa.rkt` **锯齿成因 + MSAA 原理**：glRenderbufferStorageMultisample + glBlitFramebuffer，M 键切换
2. `02-demo.rkt` **综合**（无新语法）：细长 blade + 1px 细线，多角度斜边同时暴露锯齿

★场景为什么这样设计：锯齿最明显的边 = **细 + 高对比 + 浅角度**。粗线会掩盖
锯齿，所以用 1px 细线；实心面边缘占比小，所以用细长薄片；中调色看不清，
所以用亮色 + 近黑背景。
