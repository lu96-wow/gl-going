# 16 面剔除 —— 绕序 + 背面剔除 + 可见性处理方法谱系

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

封闭实体（立方体、地形）的"背面"永远看不见，画它纯浪费。本课讲**背面
剔除**：怎么在画之前就知道哪面是背面（绕序），以及——**面剔除只是可见性
处理的其中一种方法**，深度测试、视锥剔除、遮挡剔除各管一摊。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 15 复制（本课未改动）
- `lib.rkt` —— 从 15 原样复制（面剔除是标准 gl* 调用，内联在步骤里）

1. `01-winding.rkt`  **绕序 + 背面剔除**：CCW/CW 决定正反面，glEnable(GL_CULL_FACE)
2. `02-frontface.rkt` **glFrontFace**："正面"只是约定，可翻转
3. `03-landscape.rkt` **可见性方法谱系**：深度测试 / 背面剔除 / 视锥剔除 / 遮挡剔除
4. `04-demo.rkt`     **综合**（无新语法）：C/F/R 三键 + 自转纸片
