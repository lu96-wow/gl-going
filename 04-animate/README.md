# 04 动起来与分支 —— uniform 时间 + 控制流

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

03 课把 GLSL 的类型和表达式讲透了，但画面是**静态**的。本课做两件读者最期待的事：
**让它动起来**（把时间传进 shader）和**分情况画**（if / for / 自写函数）。
画布继续用 03 课"铺满窗口的四边形 + shadertoy"这条线，最后得到老 02 课的成品——
会动的圈圈 + 呼吸 + 右上角色板。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 03 复制（本课未改动）
- `lib.rkt` —— 从 03 复制（本课未改动；uniform/timer 都内联在步骤文件里）

1. `01-timer.rkt`     **timer% 每帧重画**：清屏色随时间呼吸 → 证明"帧"在持续发生
2. `02-uniform.rkt`   **uniform uTime + glUniform1f**：时间传进 shader → 圈圈动起来
3. `03-branch.rkt`    **when/unless/cond**（if/else 分支）：右上角色板，坐标当颜色
4. `04-for.rkt`       **for 循环**（常数边界纪律）：叠加正弦 → 会动的条纹
5. `05-fn.rkt`        **define 自写函数**：同一公式、不同参数 → 三通道各自波动
6. `06-shadertoy.rkt` **综合**（无新语法）：动圈 + 呼吸 + 色板，老 02 的成品
