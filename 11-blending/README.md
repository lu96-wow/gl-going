# 11 混合 —— 半透明物体（alpha + glBlendFunc + 两个坑）

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

深度测试解决"遮挡"，但它只能二选一：片元过还是不过。半透明需要"这个片元
透出背后 60%"——这就是**混合**（blending）。本课学 alpha、混合公式，以及
透明物体最容易翻车的两个坑（渲染顺序、深度写入）。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 10 复制（本课未改动）
- `lib.rkt` —— 从 10 原样复制（半透明复用彩色立方体 cube-verts/cube-idx）

1. `01-alpha.rkt`    **alpha + 混合公式**：glBlendFunc，玻璃板透出后面的立方体
2. `02-order.rkt`    **渲染顺序坑**：先不透明后透明，多个透明要按远→近排
3. `03-depthmask.rkt` **深度写入坑**：glDepthMask(GL_FALSE)，透明不写深度
4. `04-demo.rkt`     **综合**（无新语法）：立方体 + 玻璃板，B 键切换混合
