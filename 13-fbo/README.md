# 13 离屏渲染（FBO）—— 画到纹理再贴回来

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

平时我们都画进"默认帧缓冲"（编号 0），它直接对应窗口。本课让它拐个弯：
先画到一张**离屏纹理**（看不见），再把这张纹理当普通图片整屏贴回窗口——
于是可以在片元着色器里随意改每个像素，这就是**后处理滤镜**。这个"画到纹理
再贴回去"的套路，是阴影贴图、镜面反射、屏幕后期等一切高级技巧的公共地基。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 12 复制（本课未改动）
- `lib.rkt` —— 从 12 原样复制（场景复用彩色立方体 cube-verts）

1. `01-fbo.rkt`    **FBO + 两遍渲染**：离屏画场景 → 整屏贴回（原样，证明离屏工作）
2. `02-filter.rkt` **后处理滤镜**：反色/灰度/暗角，1/2/3 键切换
3. `03-demo.rkt`   **综合**（无新语法）：旋转场景 + 公转 + 滤镜切换 + 尺寸重建
