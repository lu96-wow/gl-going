# 18 拓展：毛绒绒的发光苔藓（Moss）

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

目标：把 17 课加载的立方体，变成一块**蓝色、毛绒绒、发光的苔藓**。
这是"材质/光照"的实战综合，全部建立在已学的知识上（噪声=03/04、光照=10、
FBO=13），不引入新库。

苔藓效果拆成四个递增的效果点，正好对应四步：

1. `01-noise.rkt` **斑驳 + 毛绒质感**：hash 噪声 + FBM 让蓝色斑驳，
   噪声扰动法线 + Fresnel 边缘光 → 表面"毛乎乎、边缘发亮"
2. `02-glow.rkt`  **发光**：片元着色器加 emissive 项（苔藓自己发蓝光）
3. `03-bloom.rkt` **辉光**：13 课 FBO 后处理做 bloom（亮部晕开一圈）
4. `04-demo.rkt`  **综合**：键调参数（发光强度 / 噪声密度 / 辉光开关）

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 17-model 复制（本课未改动）
- `lib.rkt` —— 从 17-model 复制（本课未改动；obj-load-file / m4-* / build-program 照用）

★重要概念区分（每步正文会重申）：

- **emissive（自发光）** 只让苔藓"自己看起来亮"，不会照亮周围物体；
  **bloom（辉光）** 是 03 步加的后处理，让亮部在屏幕上晕开——两者叠加，
  才有"发光"的视觉错觉。
- **毛绒质感** ≠ 一根根真绒毛。本拓展做的是"质感"：噪声扰动法线模拟
  绒毛的粗糙散射 + Fresnel 模拟绒毛边缘透光。真正的纤维绒毛（shell fur）
  是另一个几何技巧，留作以后。
