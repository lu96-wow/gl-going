# 17 文本渲染 —— glyph atlas（字形表）

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

前面 16 课 GPU 只画"几何"。屏幕上的字符从哪来？本课把文字也变成几何：
**烤字帖（glyph atlas）**——用 Racket 字体引擎把字符画进位图，拼成一张纹理，
每个字符记下自己的格子(uv)与步进(advance)；画文字 = 画贴了字格子的四边形。

这是 raylib / Dear ImGui 文本渲染的原理。它复用前面每一块：纹理(10)、
像素世界正交投影(07)、混合 alpha(12)、每帧 uniform(05)、第二遍叠加(14)。

本文件夹的 lib 采用"每课一份复制"（本课不改 lib，字帖/排版都内联）：

1. `01-atlas.rkt` **烤字帖 + 画一行文字**：字符 → 位图 → R8 纹理，advance 排版采样
2. `02-cjk.rkt`   **中文支持**：字体选择 + 拉丁/中文度量一致（避免错位）
3. `03-demo.rkt`  **综合**（无新语法）：3D 场景 + 多行文字 + FPS + 3D 标签投影
