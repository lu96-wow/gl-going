# 03 GLSL 类型与表达式 —— 把着色器语言讲透（上）

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

02 课我们"照着抄"写出了 `vec2`/`vec4`/`in`/`out`/`gl_Position`，把三角形画了出来，
但没停下来理解这些类型。本课退一步，把 GLSL 语言的第一块——**类型 + 表达式**——讲透。
只此一次，之后各课遇到 GLSL 只补"用法"，不再重复解释设计。

本课的画布从"一个小三角形"换成"**铺满整个窗口的四边形**"：
片元着色器每像素拿到一个 0..1 的屏幕坐标 `vUV`，于是 shader 就变成
"**像素 = uv 的纯函数**"——最适合演示类型 / 构造器 / swizzle / 运算符 / 数学函数。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 02 复制（本课未改动）
- `lib.rkt` —— 从 02 复制（本课未改动；纯语言课，没有新工具可提取）

从本课起，每课固定结构仍是：**先 `make-window` 拿画布 → 上下文里 `define` 初始化 → 自己 `show`**。

1. `01-quad.rkt`       **铺满窗口的四边形**：第二组属性 aUV 交错存储 + stride/offset 字节布局
2. `02-types.rkt`      **类型总览**：float/int/bool/vec3 + 构造器"升维补分量"
3. `03-swizzle.rkt`    **swizzle**：`.xy`/`.yx`/`.zyx` 重排分量
4. `04-literals-ops.rkt` **字面量纪律**（`1.0` vs `1` 整数除法陷阱）+ 算术/比较逐分量
5. `05-math-fns.rkt`   **内建函数**：length/normalize/dot + clamp/mix/fract/sin/cos
6. `06-shadertoy.rkt`  **综合**（无新语法）：同心圆 + 中心渐变，把上面全部串起来
