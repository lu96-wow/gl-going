# 12 实例化 —— 一次 draw 画上百个物体

按顺序运行，每步只在前一步基础上加 1–2 个新东西。

场景里 100 个相同网格，普通做法是 100 次 draw call（每次都走一遍 CPU→GPU
的状态切换）。本课让它变成 1 次：**实例化**——把"每个实例不同的部分"做成
一个数组，GPU 画第 i 个实例时自动取第 i 行；几何本身只存一份。游戏里成千
上万的草、树、粒子都是这个套路。

本文件夹的 lib 采用"每课一份复制"：

- `lib-gui.rkt` —— 从 11 复制（本课未改动）
- `lib.rkt` —— 从 11 原样复制（实例化是标准 gl* 调用，内联在步骤里）

1. `01-instances.rkt` **实例化基础**：glVertexAttribDivisor + glDrawElementsInstanced，100 个静态立方体
2. `02-animate.rkt`  **每实例多属性**：位置 + 颜色 + 相位，方阵起浪（含 stride 陷阱）
3. `03-demo.rkt`     **综合**（无新语法）：相机环绕 + 10×10 起浪方阵
